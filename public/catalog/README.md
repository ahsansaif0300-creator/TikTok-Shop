Catalog photographs used by Distribution Center.

- Most files are product stills from DummyJSON’s public demo catalog (`cdn.dummyjson.com`), saved locally as JPEG so the shop does not depend on a third-party CDN at runtime.
- A smaller set uses Wikimedia Commons and Unsplash photographs (free licenses).
- A few fitness SKUs use original generated studio product images.

Replace any file in this folder with a licensed photo of the same name (`{sku}.jpg`) without a database change.
